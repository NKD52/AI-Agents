## Try an n8n workflow

1. Open a project marked **n8n export** or **n8n exports** and download a workflow JSON file.
2. Import the file into a test n8n instance. Connect your own credentials and configure any service IDs, webhook settings, and destinations the workflow uses.
3. Run the workflow with sample data. Review any nodes that send messages, publish content, or change records before enabling triggers.
